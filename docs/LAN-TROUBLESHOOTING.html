LAN Troubleshooting

Geometry Wars 3D Dimensions — Getting multiplayer working

Quick Checklist

  • Both devices on the same WiFi network
  • Run Play Game.bat as Administrator on the host PC
  • Use the http://192.168.x.x:3000 address shown in the console
  • Avoid 10.x.x.x (VPN) and 172.x.x.x (WSL2) addresses

Common Issues

Can't connect from laptop (but phone works)

MOST COMMON ▶
Symptoms:
  • Phone connects fine, laptop can't
  • curl gives: getsockname() errno 10022
  • Browser: "This site can't be reached"
Fix: Reset Winsock on the laptop 
REM Run as Administrator on the LAPTOP (not the host)
netsh winsock reset
REM Then RESTART the laptop

If still broken after restart:

netsh int ip reset
REM Then restart again

Why this happens: VPN software, antivirus with network inspection, or incomplete Windows Updates can corrupt the Winsock network catalog. The reset clears corrupted socket state.

Firewall blocking connections

FIREWALL ▶
Symptoms:
  • ping works but browser/curl fails
  • Connection times out (not "refused")
Fix: Add firewall rules for all profiles 
REM Run as Administrator on the HOST PC
netsh advfirewall firewall add rule name="GW-AllProfiles" dir=in action=allow protocol=TCP localport=3000 profile=any
netsh advfirewall firewall add rule name="GW-AllProfiles-2567" dir=in action=allow protocol=TCP localport=2567 profile=any

Key: profile=any makes the rule work on Private, Public, and Domain networks. Windows may classify your WiFi as "Public" which blocks most inbound connections.

To check your current profile: netsh advfirewall show currentprofile

Stale WSL2 port forwarding rules

WSL2 ▶
Symptoms:
  • Was working before, suddenly stops
  • Play Game.bat shows warning about portproxy
Fix: Run Play Game.bat as Administrator

It auto-cleans stale rules. Or manually:

netsh interface portproxy delete v4tov4 listenport=3000 listenaddress=0.0.0.0
netsh interface portproxy delete v4tov4 listenport=2567 listenaddress=0.0.0.0

Game loads but doesn't connect to server

▶
Try these:
  • Clear browser cache: Ctrl+Shift+Delete
  • Try incognito/private window
  • Try a different browser
  • Check if antivirus blocks WebSocket on port 2567

Diagnostic Steps

Run these from the connecting device (laptop/phone) to narrow down the issue:

1
Can you reach the host at all? 
ping 192.168.x.x

If this fails: different network, or host firewall blocking ICMP

2
Can you reach the web server? 
curl http://192.168.x.x:3000

If errno 10022: Winsock corruption, run netsh winsock reset

If timeout: firewall issue on host

If refused: server not running or wrong port

3
Can you reach the game server? 
curl http://192.168.x.x:2567

Should return something (even an error page means the port is reachable)

Architecture

Host PC (runs Play Game.bat as Admin) ├── Vite dev server (port 3000) — serves the game webpage ├── Colyseus game server (port 2567) — multiplayer logic └── Windows Firewall must allow both ports
Connecting Device (phone/laptop/tablet) ├── Opens http://[host-ip]:3000 in browser ├── Browser connects to ws://[host-ip]:2567 └── Must be on same WiFi subnet as host
